# ride-booking-backend
Backend for a ride-booking app: user auth, ride booking, nearest-driver matching, fare calculation, and ML-based fare prediction.
This is my ride booking backend project.
Project Description :
Ride-booking backend built step by step to learn backend development, DSA, and ML.
Feature list :
1. user signup and login
2. Book a ride
3. Match the nearest driver
4. Calculate the fare
5. Predict the fare or trip  time with ML.
